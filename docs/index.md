# finmetry

A research-first quantitative trading framework for systematic experimentation,
backtesting, and reproducible strategy development.

## Why finmetry exists

(finmetry’s research motivation)

## Design principles

- Research-first, not trading-first
- Explicit assumptions
- No hidden state
- Reproducible experiments

## Who this is for

- Quant researchers
- Systematic traders
- ML researchers working with financial data

## What finmetry is NOT

- Not a signal-selling tool
- Not a plug-and-play trading bot
